# Tonfeder 0.2.0 – Wörterbuch nach deutschem Klang

Deine eigenen Wörter werden jetzt auch dann richtig geschrieben, wenn die Spracherkennung sie anders hört.

## Neu

- **Deutscher Klangabgleich:** Bei deutschem Text vergleicht Tonfeder deine benutzerdefinierten Wörter nach ihrem Klang (Kölner Phonetik), Umlaute eingeschlossen. Aus „Frau jeschke“ wird „Frau Jäschke“, aus „frost lein“ wird „FrostLine“, aus „euro paletten“ werden „Europaletten“.
- Der Abgleich läuft auch mit Whisper-Modellen, die deine Wörter schon vorab als Hinweis bekommen.
- Wortformen mit Endung, Satzzeichen und Zeilenumbrüche bleiben erhalten.

## So nutzt du es

1. Öffne **Erweitert → Transkription → Benutzerdefinierte Wörter** und trag Namen und Fachbegriffe ein, so wie sie geschrieben werden sollen.
2. Der Schalter **Deutscher Klangabgleich** direkt darunter ist schon an.

## Außerdem

- Das Modell wird nur noch beim Start und nach einem Modellwechsel aufgewärmt. Lädt eine Aufnahme das Modell nach, wartet dein Diktat nicht mehr auf den Probelauf.
- Die Update-Anzeige im Fußbereich ist entfernt. Tonfeder sucht nicht selbst nach Updates.
