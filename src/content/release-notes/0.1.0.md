# Tonfeder 0.1.0 – erste Vorschau

Tonfeder ist eine Diktier-App für Windows und Mac: Taste halten, sprechen, loslassen, und der Text steht dort, wo dein Cursor ist. Die Spracherkennung läuft auf deinem Rechner, ohne Cloud und ohne Konto.

## Neu gegenüber Handy

- Eigener Name, eigenes Logo und Farben in Lime
- Das Sprachmodell wird beim Start geladen und aufgewärmt, damit schon das erste Diktat schnell ist
- Deutsch ist die Standardsprache, das Modell bleibt geladen
- Keine automatische Update-Suche

## Gut zu wissen

- Für Deutsch eignen sich zum Beispiel „Whisper Large V3 Turbo“ oder „Whisper Medium“ (unter Modelle)
- Windows und macOS warnen beim ersten Start, weil die App noch nicht signiert ist
- Die Mac-Version ist experimentell und noch kaum getestet

Tonfeder basiert auf [Handy](https://github.com/cjpais/Handy) von CJ Pais (MIT-Lizenz).
